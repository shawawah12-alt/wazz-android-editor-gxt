# Source code

Source aplikasi wazz ada di folder ini.

- `java/` berisi kode aplikasi, parser dan writer GXT, tampilan, serta logic editor
- `resources/` berisi string bahasa Indonesia dan Inggris, warna, style, dan icon
- `assets/namelists/` berisi daftar nama key GTA III, Vice City, dan San Andreas
- `low-level/smali/` berisi representasi low-level class aplikasi sebagai pelengkap

Package aplikasinya `com.zhawoilah.wgxt`.
